【要点】ブラウザのマイク制限について

ブラウザのセキュリティ仕様により、ファイルを直接ダブルクリック（file:///）で開くとマイクがブロックされる場合があります。
ローカルサーバー経由（localhost）で開くと確実にマイクが利用できます。

1. おすすめの起動方法 (VS Code)

VS Codeの拡張機能「Live Server」をインストールし、右クリックから「Open with Live Server」で起動してください。

2. コマンドラインでの起動 (Python)

HTMLファイルのあるフォルダでターミナルを開き、以下を実行してブラウザで http://localhost:8000 を開きます：

python -m http.server 8000

3. 無料のGemini APIキーの取得方法

Google AI Studio にアクセスし、Googleアカウントでログインして「Get API key」をクリックすると無料でAPIキーが発行されます（クレジットカード登録不要）。取得したキーを設定画面（⚙️）に貼り付けてください。
